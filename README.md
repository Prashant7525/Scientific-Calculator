# Scientific Calculator

A Python-based scientific calculator with a desktop GUI built using Tkinter.

## Features

- Basic arithmetic operations
- Power and modulus
- Square root
- Sine, cosine, and tangent
- Base-10 logarithm
- Natural logarithm
- π and e constants
- Parentheses and expression evaluation
- DEG and RAD modes
- Calculation history
- Double-click history reuse
- Keyboard input support
- Enter to calculate
- Escape to clear
- Backspace support
- Input validation
- Result formatting
- Safe expression evaluation

## Technologies

- Python
- Tkinter
- Math
- AST-based expression evaluation
